# 关注账号与中文平台采集（v0.5）

入口：http://127.0.0.1:4317/#accounts 。顶部“关注账号”统一管理哔哩哔哩、小红书和X；原来的X入口仍兼容。

## 操作流程

1. 选择平台，填写账号名称、真实主页和可选的模型厂商名称。B站支持直接输入UID；小红书要求完整用户主页，不接受短链或单条笔记链接；X支持@账号或主页。
2. 可手动标记已核对的厂商官方账号，并填写核对依据链接。该标记是用户声明，系统不会自动把同名账号认定为官方，也不会把平台登录成功等同于厂商身份认证。
3. 添加默认停用。点击平台“连接”在本项目独立Edge窗口手动登录；每个平台单独保存登录状态，不读取日常浏览器或其他项目登录档案。
4. 编辑采集时间范围与条数（默认最近30天、每轮3条），启用后可以单账号采集，也会加入现有周期任务。
5. “查看内容”进入此账号的AI信号列表，可再按平台/分析状态筛选。内容共用现有去重、分析预算、简报和Whale接口。

未内置未经核实的模型厂商官方账号。已有四个X人物来源保留，保持之前的停用状态；不会因为新增中文平台而自动启用。

## 平台实现与范围

| 平台 | 获取方式 | 正文边界 |
|---|---|---|
| Bilibili | 先尝试公开空间动态响应；不可用时转为独立Edge读取账号动态页 | 动态文字、视频标题/简介；不转写视频，不读取完整评论；跳过置顶和转发 |
| 小红书 | 独立Edge打开用户主页，定位笔记详情，核对作者、日期后提取可见正文 | 不识别图片文字或转写视频；日期未知/作者不匹配/正文不可见会失败或跳过 |
| X | 复用既有独立Edge可见时间线采集器 | 可见主帖文字；排除置顶、他人内容、未展开长文，使用账号设置的时间窗口 |

只有标题或文案不足的条目可保存为元信息，但不会自动送模型分析。材料范围与身份声明随内容保留，不将视频文案伪装成完整视频。小红书稳定笔记地址用于去重，原始可打开链接另外保存；不导出浏览器Cookie。

## API

- GET /api/v1/platforms：三平台连接状态。
- POST /api/v1/platforms/:id/connect：打开人工登录窗口；只接受 bilibili / xiaohongshu / x。
- GET /api/v1/platforms/:id/status：查看连接或最近采集状态。
- GET /api/v1/accounts：关注账号。
- POST /api/v1/accounts：platform、name、url、manufacturer、officialClaim、verificationUrl、lookbackDays、limit、enabled。默认停用。
- PATCH /api/v1/accounts/:id：编辑显示、身份声明和采集设置；不能更换平台或重绑主页。
- 原 POST /api/v1/collect {sourceId} 与启停接口继续使用；停用账号仍禁止采集。
- items 和 whale/feed 可用 platform / manufacturer / source 筛选。条目新增 platform/accountId/manufacturer/accountIdentity/openUrl，保持既有字段兼容。

## 已验证与未验证

31项Node测试通过，包含账号规范化、域名/主页校验、重复账号拒绝、编辑、官方声明、中文日期、B站作者与内容过滤、小红书归属核验和安全打开链接。

Edge本地夹具检查了三平台连接按钮路由（登录回执模拟）、账号添加/编辑/启用、采集按钮（回执模拟）、查看账号内容、平台筛选与移动端布局。B站动态DOM、小红书主页和笔记DOM在真实Edge离线页面提取并归一化通过。截图 accounts-demo.png / accounts-mobile.png 来自隔离内存库，QA厂商与账号均为测试夹具，没有写入用户数据库。

真实联网诊断：Bilibili公开接口返回HTTP412，未登录Edge未发现可用动态，采集器如实返回PAGE_UNAVAILABLE，没有将其判为零条新动态。小红书入口HTTP200，但尚未完成真实账号登录后的笔记采集验证。X此前按用户要求暂缓在线联调，本轮没有自动重试或打开X登录窗口。

因此，本轮完成的是可配置的账号入口与采集器接入，不等于所有平台已能在当前网络/登录状态下成功抓取。需要用户提供真实官方主页并完成人工登录，再逐账号验收；遇到安全验证不绕过。

## 登录与切换采集账号

在“关注账号 → 平台连接”点击“登录 / 切换账号”。登录成功后窗口保持打开，可在平台自己的头像菜单退出旧账号，再登录新账号。完成后手动关闭该独立浏览器窗口，或回工作台点击“完成登录”。系统设置中的 X 入口使用同样操作。

窗口打开期间该平台暂停采集，避免浏览器档案冲突；关窗后释放采集锁。窗口没有自动关闭倒计时。每个平台保存一个当前采集登录状态，不提供多个登录档案并行采集；切换登录账号不改变已关注的厂商列表。

`POST /api/v1/platforms/:id/finish` 关闭该平台的手动登录窗口并释放锁；重复调用安全，不关闭后台采集窗口。
