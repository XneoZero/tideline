# 模型与费用

当前默认配置示例：`FEED_LLM_BASE_URL=https://api.deepseek.com`，`FEED_LLM_MODEL=deepseek-chat`。这是模型请求名，不代表已核实其当前服务端底层版本；分析回执另存 resolvedModel 与供应商返回的token用量。

**DeepSeek官方API并非免费。** 官方说明按输入和输出tokens计费，费用从充值或赠送余额扣除。网页/App免费聊天、开源模型权重、赠送API额度是不同概念，不能把其中任何一项理解成这个项目的官方API永久免费。

价格以 [DeepSeek官方价格页](https://api-docs.deepseek.com/quick_start/pricing/) 为准。本项目不读取你的账单，无法报告已经实际扣款的精确金额；有些历史调用发生在日账本功能加入之前。

- 新安装默认关闭自动运行；已有本地配置保持原值。
- 调度默认每6小时、每轮最多3条、上海自然日最多12次模型尝试；失败也计数。
- 单次输出最多2000 tokens；调用数/输出上限不是精确金额封顶，输入tokens也会计费。
- 日上限设为0可停止新模型请求，采集与阅读仍可使用。
- 支持配置其他Chat Completions兼容服务。使用本机推理服务时，API是否收费由该服务决定，本机运行仍消耗计算资源。
- AstrBot只读接口与插件不触发模型调用；已有资讯的查询没有新增分析费用。

不要把真实密钥写入README或提交到Git；只在本机环境或被忽略的 `.env` 中配置。
